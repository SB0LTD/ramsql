Evidence

    
Every number is reproducible.

    
Benchmarks run from published harnesses in public GitHub Actions and local runs, with raw logs, binary hashes and source snapshots retained. We publish the cases where we are not first, too.

  

  

    
Correctness first
Each timed request is checked against an independent Python model and a 2,038-check PostgreSQL oracle. A fast wrong answer scores zero.

    
Latest versions
PostgreSQL 16 and 18 and the newest stable IRDB, verified against the live NuGet feed, run on the same host with matched settings.

    
Open methodology
Warmup, alternating engine order, five-trial medians, equal JVM heap. Commands and harnesses are in the repository.

    
Where we are still climbing
On a one-million-row analytic mix with eight clients IRDB currently leads. Joins, large working sets and recovery speed are in active qualification.

Engine

    
A database with nothing to waste.

  

  

    
⚡
Pure Sig
The whole runtime is Sig. No C libraries, no SQLite, no language runtime to load.

    
🔒
Durable by design
Flush-before-publication WAL, exclusive writer locking and fail-closed recovery.

    
🔑
SCRAM auth
PostgreSQL SCRAM credentials are required by default on the server.

    
⚖
Atomic statements
Statement atomicity and resource ownership on every error path.

    
📦
Bounded memory
Explicit capacity profiles. Inspect capacity before loading, no surprise growth.

    
🔄
Offline backup
Validated backups that never overwrite a destination.
